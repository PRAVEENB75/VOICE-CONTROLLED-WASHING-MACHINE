Core Embedded System Components
HARDWARE ARCHITECTURE SPECIMENS

Comprehensive breakdown of the 8 physical hardware modules engineered into this voice-controlled, energy-monitored smart appliance IoT system.

8 Hardware Modules
230V Mains Rating
32-bit Dual-Core ESP32
Core Controller

ESP32 NodeMCU Board

DESCRIPTION

A powerful 32-bit microcontroller with built-in Wi-Fi, Bluetooth, and standard pin headers. It serves as the main brain for processing data and hosting the web server.

PROJECT USAGE

Runs the web server, processes voice commands, reads PZEM-004T data, and triggers the relay and speaker alerts.

Sensor Module

PZEM-004T V3.0 Energy Meter (with CT Coil)

DESCRIPTION

A high-precision electrical sensor module designed to measure AC voltage, current, active power, and energy. Uses a split-core current transformer for non-invasive AC current sensing.

PROJECT USAGE

Measures real-time power consumption of the washing machine load and sends data to the ESP32 to calculate billing.

Switch Actuator

5V 1-Channel Relay Module

DESCRIPTION

An optocoupler-isolated electromechanical switch that allows low-voltage DC microcontrollers to control high-voltage AC devices safely.

PROJECT USAGE

Acts as the main power switch to turn the 230V AC load (simulated washing machine) ON and OFF based on voice commands.

Audio Decoder

DFPlayer Mini MP3 Module

DESCRIPTION

A compact hardware audio decoder board that reads and plays high-quality .mp3 files directly from a MicroSD card.

PROJECT USAGE

Plays pre-recorded voice audio reminders asking the user to clean the tumbler filter once a wash cycle ends.

Acoustic Output

8Ω 2W Mini Speaker

DESCRIPTION

A compact audio output transducer optimized for clear voice speech playback from low-power audio drivers.

PROJECT USAGE

Outputs the voice alert prompts triggered by the DFPlayer Mini module.

Local Display

16x2 Character LCD Display (I2C)

DESCRIPTION

An alphanumeric display screen integrated with an I2C backpack adapter to reduce wiring down to just two signal pins.

PROJECT USAGE

Displays local live readings of Power (W), Energy (kWh), and calculated Bill (₹) directly on the physical board.

Safety Sensor

Micro Limit Switch

DESCRIPTION

A miniature roller-lever mechanical switch that toggles electrical contact when physical pressure is applied or released.

PROJECT USAGE

Detects when the tumbler door flap is opened to automatically clear and reset the voice maintenance alert.

Mains Power

AC 3-Pin Power Cord (5A)

DESCRIPTION

A standard grounded three-wire AC cable designed to safely connect tabletop appliances to domestic wall sockets.

PROJECT USAGE

Supplies 230V AC mains power to both the high-voltage load and the 5V power supply safely.
